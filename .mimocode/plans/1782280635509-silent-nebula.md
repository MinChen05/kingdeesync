# 重新设计日志中心页面

## 当前问题

现有 `log_center_page.py`（707行）布局过于密集：顶部 5 个统计卡片 + 4 个下拉筛选器 + 左侧模块列表 + 右侧表格 + 底部状态栏，信息过载且筛选器冗余。

## 新设计

**布局**：全宽日志流，筛选器精简为工具栏，无左侧模块列表。

```
┌─────────────────────────────────────────────────────┐
│ 日志中心                     [清空] [复制] [导出]   │  ← 标题 + 操作按钮
├─────────────────────────────────────────────────────┤
│ 时间范围 ▼  [全部|信息|警告|错误]  🔍搜索日志...    │  ← 单行工具栏
├─────────────────────────────────────────────────────┤
│ 时间              级别   模块          消息          │
│ 2025-05-28 10:15  错误  金蝶 API     登录失败...    │  ← 表格（全宽）
│ 2025-05-28 10:12  信息  数据同步     写入完成        │
│ 2025-05-28 10:10  警告  SQL Server   连接超时        │
│ ...                                                  │
├─────────────────────────────────────────────────────┤
│ 128 条  ·  错误 3  ·  警告 12    [仅错误] [自动滚动]│  ← 底部摘要栏
└─────────────────────────────────────────────────────┘
```

## 修改文件

### 1. `src/gui/pages/log_center_page.py`

**删除**：
- 5 个统计卡片（`_create_stat_card` + stat_defs）
- 4 个顶部下拉筛选器（combo_time/combo_level/combo_module/combo_task 改为内联按钮）
- 左侧模块列表（`_ModuleItem` + sidebar_scroll + `_load_module_list`）
- 底部冗余控件（refresh_combo、page_size_label 等）

**新增**：
- 单行工具栏：时间范围 QComboBox + 级别切换按钮组（4 个 QPushButton，checkable）+ 搜索框
- 底部摘要栏：筛选结果数/错误数/警告数 + "仅显示错误"开关 + "自动滚动"开关
- 表格行点击 → 底部展开详情面板（显示完整消息 + 原始字段）

**保留**：
- `_read_jsonl_logs` 数据读取
- `_friendly_level` / `_friendly_module` / `_friendly_message` 翻译
- `apply_filters` 筛选逻辑
- 清空/复制/导出功能

### 2. `assets/styles.css`

替换现有 `lc-*` 样式（约 90 行），新增：
- `lc-toolbar` 工具栏样式
- `lc-level-btn` / `lc-level-btn:checked` 级别切换按钮样式
- `lc-summary-bar` 底部摘要栏样式
- `lc-detail-panel` 详情展开面板样式
- `lc-table-row:selected` 行选中样式

## 不修改

- `data_table.py`、`common.py`、`design_tokens.py`、`page_shell.py` — 复用现有组件
- `_FALLBACK_LOG_ROWS` / `_FALLBACK_MODULES` — 移除硬编码回退数据

5. 点击行展开详情
6. 底部摘要统计正确
7. 清空/复制/导出正常
