# 数据库字段精度优化方案

## 优化目标
精简数据库存储空间，将过度精确的 `decimal(23,10)` 字段调整为合理精度。

## 优化原则

### 1. 金额类字段 → `decimal(18,2)`
- **适用于**: 价格、总额、余额等财务金额
- **精度**: 2 位小数（分）
- **节省空间**: 31% (13字节 → 9字节)

### 2. 数量类字段 → `decimal(18,4)`
- **适用于**: 采购数量、生产数量、BOM 用量
- **精度**: 4 位小数
- **节省空间**: 31% (13字节 → 9字节)

### 3. 比率类字段 → `decimal(5,2)`
- **适用于**: 折扣率、税率
- **精度**: 2 位小数
- **节省空间**: 62% (13字节 → 5字节)

### 4. 库存类字段 → `decimal(18,6)`
- **适用于**: 即时库存基本数量
- **精度**: 6 位小数
- **节省空间**: 31% (13字节 → 9字节)

## 优化范围

- **总表数**: 11 个
- **总字段数**: 49 个
- **预计空间节省**: 30-60%
