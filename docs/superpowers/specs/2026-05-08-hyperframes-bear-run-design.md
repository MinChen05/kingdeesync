# HyperFrames 小熊虫奔跑视频设计

**日期：** 2026-05-08

## 目标

基于用户提供的参考 PNG，生成一个 `9:16`、`15s`、无音乐无字幕的短视频。主体是一只软萌手绘风“小熊虫”，在草地/自然场景中持续奔跑，并在中段完成一次小跳后继续奔跑。

## 视觉方向

- 保持参考图的贴纸感、圆润轮廓和浅奶油色主体，不改成写实动物。
- 背景采用暖色自然场景：浅天空、柔和云层、分层草地、少量小花。
- 用轻微纸感/颗粒和柔和光晕避免纯平背景。
- 不添加标题、字幕、UI 元素或品牌文案。

## 动作方案

- 不伪造逐帧赛跑，而采用单张角色图的木偶式动画。
- 用以下动作组合表达奔跑：
  - 主体上下起伏
  - 轻微前倾和回弹
  - 水平位移
  - 落地时的轻微挤压与回弹
  - 影子缩放与透明度变化
  - 草屑/速度线的辅助运动
- 中段加入一次小跳，形成 “跑一段 -> 小跳 -> 继续跑” 的节奏峰值。

## 节奏分段

1. `0s-5s`：建立环境与跑步节奏。
2. `5s-8s`：完成小跳，镜头与背景略提速，制造轻盈感。
3. `8s-15s`：落地继续跑，前景草叶和远景云朵持续运动，平稳收束。

## 技术实现

- 在仓库内新建独立目录 `video/hyperframes-bear-run/`，避免影响现有业务代码。
- 使用 HyperFrames 单场景 HTML 组合渲染 `1080x1920` 视频。
- 角色素材直接引用用户提供的 PNG。
- 若本地不存在 HyperFrames 运行依赖，则通过 `npm`/`npx` 在该目录内安装最小依赖。

## 验收标准

- 输出 `mp4` 文件，时长约 `15s`。
- 角色风格与参考图一致，不出现明显拉伸变形或闪烁。
- 视频可正常播放，场景、角色、影子和背景层次完整。
- 如环境允许，完成 `lint` / `validate` / `render`。
